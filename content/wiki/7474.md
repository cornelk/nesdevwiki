The **7474** (variants 74LS74, 74HC74) is a 74-series logic IC with two independent D flip-flops.<sup><span id="cite_ref-1"></span>[\[1\]](#cite_note-1)</sup>

## Pinout {#Pinout}

             .--\/--.
    /1RST -> |01  14| -- +5V
       1D -> |02  13| <- /2RST
     1CLK -> |03  12| <- 2D
    /1SET -> |04  11| <- 2CLK
       1Q <- |05  10| <- /2SET
      /1Q <- |06  09| -> 2Q
      Gnd -- |07  08| -> /2Q
             `------'
