NES 2.0 Mapper 342 is used for the homebrew COOLGIRL multicart. In addition to native registers, it can simulate about 25 commercial-era mappers on a hardware level. It can address up to 128 MiB of PRG-ROM, 512 KiB of CHR-RAM, and 32 KiB of WRAM. Like the [COOLBOY](../NES_2.0_Mapper_268/) mapper that inspired it, CHR-RAM is filled with pattern data copied from PRG-ROM by the multicart menu after a game has been selected. Its UNIF board name is just **COOLGIRL**.

## Registers {#Registers}

Range: \$5000-\$5FFF

Mask: \$5007

All registers are \$00 on power-on and reset.

### <span id=".245xx0"></span>\$5xx0 {#.245xx0}

     7  bit  0
     ---- ----
     PPPP PPPP
     |||| ||||
     ++++-++++-- PRG base offset (A29-A22)

### <span id=".245xx1"></span>\$5xx1 {#.245xx1}

     7  bit  0
     ---- ----
     PPPP PPPP
     |||| ||||
     ++++-++++-- PRG base offset (A21-A14)

### <span id=".245xx2"></span>\$5xx2 {#.245xx2}

     7  bit  0
     ---- ----
     AMMM MMMM
     |||| ||||
     |+++-++++-- PRG mask (A20-A14, inverted+anded with PRG address)
     +---------- CHR mask (A18, inverted+anded with CHR address)

### <span id=".245xx3"></span>\$5xx3 {#.245xx3}

     7  bit  0
     ---- ----
     BBBC CCCC
     |||| ||||
     |||+-++++-- CHR bank A (bits 7-3)
     +++-------- PRG banking mode (see below)

### <span id=".245xx4"></span>\$5xx4 {#.245xx4}

     7  bit  0
     ---- ----
     DDDE EEEE
     |||| ||||
     |||+-++++-- CHR mask (A17-A13, inverted+anded with CHR address)
     +++-------- CHR banking mode (see below)

### <span id=".245xx5"></span>\$5xx5 {#.245xx5}

     7  bit  0
     ---- ----
     CDDE EEWW
     |||| ||||
     |||| ||++-- 8KiB WRAM page at $6000-$7FFF
     |+++-++---- PRG bank A (bits 5-1)
     +---------- CHR bank A (bit 8)

### <span id=".245xx6"></span>\$5xx6 {#.245xx6}

     7  bit  0
     ---- ----
     FFFM MMMM
     |||| ||||
     |||+ ++++-- Mapper code (bits 4-0, see below)
     +++-------- Flags 2-0, functionality depends on selected mapper

### <span id=".245xx7"></span>\$5xx7 {#.245xx7}

     7  bit  0
     ---- ----
     LMTR RSNO
     |||| |||+-- Enable WRAM (read and write) at $6000-$7FFF
     |||| ||+--- Allow writes to CHR RAM
     |||| |+---- Allow writes to flash chip
     |||+-+----- Mirroring (00=vertical, 01=horizontal, 10=1Sa, 11=1Sb)
     ||+-------- Enable four-screen mode
     |+-- ------ Mapper code (bit 5, see below)
     +---------- Lockout bit (prevent further writes to all registers)

## PRG banking modes {#PRG_banking_modes}

     | ==== + ===== + ===== + ===== + ===== + ======================================== |
     | 000  |       A       |       C       | UxROM, MMC4, MMC1 mode #3, etc.          |
     | ---- + ------------- + ------------- + ---------------------------------------- |
     | 001  |       C       |       A       | Mapper 97 (TAM-S1)                       |
     | ---- + ------------- + ------------- + ---------------------------------------- |
     | 010  |           Reserved            |                                          |
     | ---- + ----------------------------- + ---------------------------------------- |
     | 011  |           Reserved            |                                          |
     | ---- + ----- + ----- + ----- + ----- + ---------------------------------------- |
     | 100  |   A   |   B   |   C   |   D   | Universal, used by MMC3 mode 0, etc.     |
     | ---- + ----- + ----- + ----- + ----- + ---------------------------------------- |
     | 101  |   C   |   B   |   A   |   D   | MMC3 mode 1                              |
     | ---- + ----- + ----- + ----- + ----- + ---------------------------------------- |
     | 110  |               B               | Mapper 163                               |
     | ---- + ----------------------------- + ---------------------------------------- |
     | 111  |               A               | AxROM, MMC1 modes 0/1, Color Dreams      |
