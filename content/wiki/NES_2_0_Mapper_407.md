**NES 2.0 Mapper 407** is used by the *Win, Lose or Draw* Plug-n-Play which came built into a tablet. The game uses the [VT03](../VTxx/) enhanced NOAC. The submapper field is set to 15 to denote the same CPU opcode encryption method as Mapper [256](../NES_2.0_Mapper_256/)'s, submapper 15. The NOAC's PRG A24 selects between PRG-ROM (0) and 64 KiB of PRG-RAM (1), which the OneBus hardware can map to both CPU and PPU address space.
